# Padrão Oficial — Coleta de Dados FÊNIX

## Status

APROVADO COMO PADRÃO VISUAL E FUNCIONAL DA COLETA.

A partir desta aprovação, a coleta de dados da FÊNIX Intelligent BPO não deve ser redesenhada sem aprovação expressa do responsável pelo projeto. Alterações futuras devem ser tratadas como correções funcionais, ajustes de conteúdo, integrações ou refinamentos pontuais.

## Identidade visual obrigatória

- Usar exclusivamente a logo oficial **FÊNIX Intelligent BPO**.
- Não usar logos alternativas, recriadas, genéricas ou geradas por IA.
- Usar exclusivamente a paleta oficial da FÊNIX BPO.
- Base visual predominante: preto, com dourado oficial FÊNIX e tons de apoio já aprovados da identidade.
- A logo oficial deve permanecer no canto superior direito em todas as etapas, inclusive nas versões desktop e mobile.
- Marca d’água, quando utilizada, deve usar exclusivamente o símbolo oficial FÊNIX disponível nos ativos do projeto.
- Não usar qualquer outra marca d’água, símbolo, asa ou elemento semelhante que não seja ativo oficial da FÊNIX.

## Estrutura visual congelada

- Wizard de 9 etapas.
- Uma etapa por tela.
- Cabeçalho centralizado com `LEVANTAMENTO DE DADOS` e o fluxo comercial abaixo.
- Navegação entre etapas livre e clicável.
- Barra de progresso baseada em informações realmente preenchidas, e não em etapas visitadas.
- Layout full viewport no desktop, com rolagem interna apenas quando necessária.
- Layout responsivo no mobile, com quebra adequada para uma coluna e rolagem natural.
- Não voltar ao formulário longo antigo.
- Não alterar a estrutura visual sem aprovação expressa.

## Regras de experiência

- O cliente não deve ver nomenclaturas internas como `Dados V2`.
- O cliente deve ver a experiência comercial `Levantamento de Dados`.
- A coleta deve permitir mudança de etapa sem exigir preenchimento prévio.
- A validação obrigatória deve ocorrer somente no envio final.
- Consulta de CNPJ deve preencher, quando disponível, dados cadastrais e endereço.
- Segmentos de atuação podem ser múltiplos e devem ser separados da atividade principal oficial do CNPJ.
- Campos de volumetria não devem vir preenchidos automaticamente com `0`.
- A etapa de softwares/repasses é opcional e deve explicar claramente o que é repasse.

## Governança

- Esta é a referência padrão da coleta a partir de 03/09/2026.
- Refinar, não redesenhar.
- Produção somente após homologação visual e funcional.
- O link público oficial continua sujeito à aprovação antes de qualquer substituição da rota atual.
